1 Current State vs Required Architecture

❌ Current Mobile Implementation

• Mobile stores a single IP address in localStorage.getItem('nativePrinterAddress').
• All prints (Bill, KOT, Cashier, Report) are routed to this single IP.
• Category-wise KOTs (Kitchen, Bar, Grill) and Section/Order-type routing rules are ignored on mobile.

✅ Target Multi-Wi-Fi Architecture

• Mobile maintains a Network Printer Registry (Name $\leftrightarrow$ IP & Port).
• When placing an order, the items are dynamically split and filtered by Category, Section, and Product mappings.
• Mobile opens parallel TCP sockets to each designated Wi-Fi thermal printer simultaneously.

B. Dynamic Order & KOT Routing Dispatcher

Create a centralized routing dispatcher (mobilePrintDispatcher.ts) that receives cart items and resolves their destination printers using the priority hierarchy:
Hierarchy: Product Mapping > Category Mapping > Section Mapping > Default KOT Printer 

// src/features/pos/utils/mobilePrintDispatcher.ts
import { printEscPosMarkupToAddress } from '../services/qzService';
import { generateKotMarkup } from './escPosGenerator';

interface PrintJob {
  printerName: string;
  ipAddress: string;
  port: number;
  items: any[];
}

export async function dispatchMobileKotPrints(cartItems: any[], orderMeta: any) {
  const printerSettings = JSON.parse(localStorage.getItem('posPrinterData') || '{}');
  const networkPrinters: Record<string, { ip: string; port: number }> = 
    JSON.parse(localStorage.getItem('networkPrintersDirectory') || '{}');

  const categoryMappings = printerSettings.categoryPrinter || [];
  const productMappings = printerSettings.productPrinter || [];
  const defaultKotPrinter = printerSettings.generalPrinter?.kotPrinter || 'Kitchen-KOT';

  // 1. Group items by target printer name
  const itemsByPrinter = new Map<string, any[]>();

  for (const item of cartItems) {
    // Check product mapping first, then category mapping, fallback to default
    const prodMap = productMappings.find((p: any) => p.productId === item.productId);
    const catMap = categoryMappings.find((c: any) => c.categoryId === item.categoryId);

    const targetPrinter = prodMap?.firstPrinter || catMap?.firstPrinter || defaultKotPrinter;

    if (targetPrinter && targetPrinter !== 'No Printer') {
      if (!itemsByPrinter.has(targetPrinter)) itemsByPrinter.set(targetPrinter, []);
      itemsByPrinter.get(targetPrinter)!.push(item);
    }
  }

  // 2. Dispatch KOT jobs to each designated Wi-Fi printer in parallel
  const printPromises = Array.from(itemsByPrinter.entries()).map(async ([printerName, items]) => {
    const printerNet = networkPrinters[printerName];
    if (!printerNet?.ip) {
      console.warn(`[Mobile Print] No IP configured for printer: ${printerName}`);
      return;
    }

    const kotMarkup = generateKotMarkup({
      cartDetails: items,
      data: { ...orderMeta, stationName: printerName }
    });

    await printEscPosMarkupToAddress(kotMarkup, printerNet.ip, printerNet.port || 9100);
  });

  // 3. Print Master KOT if enabled
  if (printerSettings.generalPrinter?.masterKOT && printerSettings.generalPrinter.masterKOT !== 'No Printer') {
    const masterPrinterName = printerSettings.generalPrinter.masterKOT;
    const masterNet = networkPrinters[masterPrinterName];
    if (masterNet?.ip) {
      const masterMarkup = generateKotMarkup({ cartDetails: cartItems, data: { ...orderMeta, isMasterKot: true } });
      printPromises.push(printEscPosMarkupToAddress(masterMarkup, masterNet.ip, masterNet.port || 9100));
    }
  }

  await Promise.allSettled(printPromises);
}

C. Updated Capacitor Plugin Call

// src/features/pos/services/qzService.ts
export const printEscPosMarkupToAddress = async (markup: string, address: string, port = 9100): Promise<void> => {
  if (!Capacitor.isNativePlatform()) return;

  await BitezoPrinter.printEscPos({
    markup,
    type: 'tcp',
    address: address.trim(),
    port: port,
  });
};

A. Network Printer Profile Table

Store the physical Wi-Fi printer directory per Branch / Counter so mobile devices download the full network topology upon login: 

public class NetworkPrinterProfile
{
    [Key]
    public int Id { get; set; }
    public int BranchId { get; set; }
    public string PrinterName { get; set; } = string.Empty; // e.g. "Kitchen-KOT", "Bar-Printer"
    public string ConnectionType { get; set; } = "TCP";     // "TCP" or "Bluetooth"
    public string IpAddress { get; set; } = string.Empty;   // "192.168.1.101"
    public int Port { get; set; } = 9100;
    public bool IsActive { get; set; } = true;
}
